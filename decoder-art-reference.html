01
Color ≠ meaning
Never signal a game state by color alone. Pair with shape, icon, position, or motion.
02
Off-white grounds
Low-glare, tint-safe backgrounds. Never pure white — it glares for dyslexic readers.
03
Vector-first
One source scales iPhone → iPad → @3x. This is the rule that keeps iPad cheap.
04
No red X, ever
There is no "wrong" in Decoder. A miss drifts back warmly — never a buzzer or a frown.

Definition of Done

An asset ships only when every box is true.

  • Vector-first — or authored at largest target + @1x/@2x/@3x if raster
  • Named to its key — app_object_state
  • Transparent background — sits on any user tint
  • Layered / rig-ready if it animates — never flattened
  • Light and dark variants, both designed
  • Reduce-Motion variant if animated
  • Contrast AA; no meaning carried by color alone
  • Clean on all four tints — cream / blue / grey / off-white
  • Reads at smallest size — icons legible at 60 px
  • Tone check — warm, never babyish, never corrective
  • Exists in the schema — no orphan art, no missing art

Failure is invisible

Shame is the #1 reason these kids quit. A miss simply drifts back for later — the guide stays encouraging. No red X. No buzzer. No frown. And the momentum meter has a protected rest-day state, so one bad day never resets progress. Get this system right and the whole product's tone works.
