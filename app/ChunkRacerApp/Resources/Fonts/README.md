# Font Drop

Drop the licensed font files here. The app will register them automatically at launch.

Expected files (matching Info.plist UIAppFonts):
- FredokaOne-Regular.ttf (or FredokaOne.otf)
- OpenDyslexic-Regular.otf
- OpenDyslexic-Bold.otf
- LexendDeca-Regular.ttf

The code falls back to the system rounded font when any bundled face is missing, so the app builds and runs without these files — but the art-bible typography is not final until they are present.
